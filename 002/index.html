The main build

A Secret Santa that keeps the secret

No more names in a hat. Type in everyone's names and the page draws them, makes sure nobody gets themselves, and only shows each person their own match.

  1. Ask for the page

    TipMost AI apps can show the page right in the chat. Look for a canvas, artifact or preview option.

    In ChatGPTIt writes the page as code in the chat. If you see a Preview option, use it to try the page.

    In ClaudeThe finished page appears as an artifact beside the chat, ready to try straight away.

    In GeminiBefore you send, tap Canvas under the message box. Gemini then builds the page in its Canvas panel, where you can try it.

    In CopilotUse Microsoft 365 Copilot (a work or school account, or a Microsoft 365 Personal or Family plan). Include the word "interactive" and it builds a Page. Switch on Preview to try it.

  2. Make it yours

    Ask for one change at a time. Small requests get better results than a long list.

  3. Do the big reveal

    Draw the names once, then pass the phone round. Each person taps their name, has a peek, taps Hide and hands it on.

    Worried someone will forget who they've got? Ask for a backup:

    This one works best with everyone in the same room. If you share a link instead, each phone would draw its own names.

Feature in 60 seconds

Voice mode: just talk to it

Too busy to type? Tap the voice button and have a proper conversation out loud. You can interrupt, change your mind and ask follow-ups, just like talking to a person.

Where to find itLook for the sound-wave or microphone button next to where you type. Gemini calls it Gemini Live.

In ChatGPTTap the sound-wave button next to the message box to start a voice chat.

In ClaudeIn the Claude app, tap the voice button next to the message box to start a spoken conversation.

In GeminiTap Live next to the message box to start Gemini Live.

In CopilotTap the microphone in the Copilot app to talk with Copilot Voice.

Try it for: talking through a recipe while your hands are covered in flour, practising a tricky conversation, or settling a quiz-night argument.

Names, features and limits vary by app and plan, so check what yours includes.
